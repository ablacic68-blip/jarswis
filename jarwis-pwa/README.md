# JARVIS PWA AI Assistant

Sadržaj ove arhive:
1. main.py - FastAPI backend server
2. requirements.txt - Potrebni paketi za server
3. index.html - Web sučelje za mobitel s mikrofonom i glasom

Upute za objavu:
1. Ekstraktirajte sve datoteke u jednu mapu na računalu.
2. Učitajte datoteke na vaš GitHub repozitorij jarvis-pwa.
3. Povežite repozitorij s Render.com (za main.py) i Netlify / Vercel (za index.html).
4. U index.html zamijenite BACKEND_URL sa stvarnim Render URL-om.
